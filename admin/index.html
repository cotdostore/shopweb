Tạo ID khách hàng

ID này cũng là mật khẩu khách nhập trên web.

Tạo qua lệnh /id trong Messenger để gắn ID với đúng cuộc chat. ID tạo ở đây được quản lý tại web.

Cấp quyền theo thời hạn

Cấp lại sẽ tính hạn mới từ hiện tại. Hết hạn tự chặn quyền ở máy chủ, kể cả khi khách còn đăng nhập.

Thêm tài khoản

Nếu tài khoản có nguồn Docs, lần đồng bộ kế tiếp sẽ lấy lại giá trị trong Docs.

Đồng bộ Google Docs

  1. Tải hai file script ở dưới và tạo dự án tại Google Apps Script.
  2. Dán Code.gs và bật hiển thị manifest để dán appsscript.json.
  3. Tạo token, rồi vào Project Settings → Script properties, thêm các giá trị được hiển thị.
  4. Chạy installSync một lần bằng tài khoản có quyền đọc Docs và cấp quyền Google. Script sẽ đồng bộ ngay, rồi tự lấy danh sách Docs đang bật trên web mỗi phút. Khi thêm hoặc đổi Docs trên web, không cần sửa script hay tạo lại token.
